像素昼夜开关

Pixel Daylight Switch

像素风

把一天的光线，装进一枚可以亲手拨动的开关。拖动控制器，天空从清晨走向黄昏，再沉入夜色；光线、环境与微缩场景一起变化。

拨动时间

THE CORE IDEA

这不是一个只负责开与关的按钮。它把时间变成可以触摸的连续过程：白昼、黄昏与夜晚不再是三个孤立状态，而是一次有过渡、有情绪的光线变化。

场景不是背景贴图，而是时间变化的承载体。相同的时间进度，在不同空间里形成不同的观看感受。

交互方式拖动 · 切换 · 连续过渡
视觉语言像素场景 · 折射玻璃
体验重点时间感与氛围变化
作品类型可交互界面实验

像素圆环

INTERACTIVE PIXEL WORLD

像素风

让一座微缩世界沿着时间运转。太阳、月亮、天空与地表共同构成一条昼夜轨道；你可以拖动圆环，也可以切换不同的世界构图，观察同一段时间如何改变整个场景。

data-scene 可选 countryside（田园）、planet（星球）、world（环形世界）；data-composition 可选 art（主页那种下沉构图）或 full（完整圆环）。

让世界转起来

A WORLD IN MOTION

像素圆环把时间具象成一条可以操作的轨道。它关注的不是简单的昼夜切换，而是一个世界如何随着时间持续改变：天空的色彩、太阳与月亮的位置，以及房屋灯光的明暗。

圆环是时间的刻度，也是场景的组织方式。它让抽象的时间拥有了位置、方向与距离感。

核心机制圆环拖动 · 时间映射
环境变化天空 · 日月 · 云层 · 灯光
体验方式连续探索与版本切换
视觉方向像素微缩世界

从名字到世界

PEOPLE / PLACES

代码仓库记录了协作，却很少让人直观看见协作者之间的空间关系。投稿者地球尝试把这些信息转化为地球上的标记，让每一次探索都成为一次发现。

它既是一张可旋转的地理画布，也是一种关于开源社区的观看方式。拖动地球改变视角，寻找标记，选择标记查看贡献者资料，再从资料卡进入相关作品。

主要对象贡献者与地理位置
浏览方式旋转 · 缩放 · 搜索

收藏长廊

THE BOOKMARK HALL

空间交互程序化像素艺术

把收藏变成一段可以走进去的空间。作品不再只是列表里的缩略图，而是长廊墙面上的一幅幅画；前进、回望、靠近，让浏览变成一次空间漫游。

查看项目↗实验室↗

空间体验

在长廊中前进、后退并浏览墙上的作品画框，靠近感兴趣的作品即可打开对应内容。长廊只展示宿主页面主动传入的收藏数据，不读取访问者的账号或本地收藏，也不连接特定网站账号。

Canvas 2D · Ray casting · Data-driven environment

嵌入你的网页

<script src="https://gsvegetable.github.io/gongshui-open-source/bookmark-hall/embed.js?v=1.2.0" data-icons="0"></script>
<script>
  const hall = document.querySelector('[data-gongshui-embed="bookmark-hall"]').gongshuiEmbed;
  hall.ready.then(() => hall.setItems([
    { id: 'work-a', title: '我的作品', src: 'https://example.com/work-a' }
  ]));
</script>

长廊需要由你自己的页面调用 setItems() 传入收藏列表。示例中的作品名称和网址请替换成你自己的内容；组件不会擅自读取访客的收藏。

走进收藏

A WALKABLE ARCHIVE

收藏长廊试着改变传统收藏列表的观看方式。它把条目放进一个可探索的空间，让人通过移动和观察来发现内容，而不是不断向下滚动一串卡片。

空间本身成为索引，画框则成为通往作品的入口。长廊只展示宿主页面主动传入的数据，不读取访问者的账号或本地收藏。

空间形式可探索的像素长廊
浏览动作前进 · 后退 · 靠近
内容来源由宿主页面主动传入
技术方向Canvas 2D · Ray casting

导航交互系统

NAVIGATION INTERACTION SYSTEM

界面设计微交互

一组由 24 枚像素按钮组成的交互实验。每枚按钮都有自己的动作节奏与反馈方式；从按下、回弹到连续触发，探索界面里那些短暂却决定手感的瞬间。

查看项目↗实验室↗

嵌入你的网页

<script src="https://gsvegetable.github.io/gongshui-open-source/navigation-interaction/embed.js?v=1.4.2"></script>

默认展示完整的 24 个按钮。可用 data-sample="7" 只显示一个样本，或用 data-samples="0,2,7,14" 组合多个按钮。

让按钮有自己的性格

MICRO INTERACTIONS

按钮不只是图标的容器。按下时的位移、回弹时的节奏、触发后的反馈，都会影响用户对界面的感受。

这套系统把 24 枚像素按钮作为样本，分别探索它们的点击动画与状态变化。每个按钮可以拥有独立的动作节奏，也可以参与组合与联动。

组件数量24 枚像素按钮
视觉状态黑白图标
交互反馈按压 · 回弹 · 延迟
设计重点独立动效与联动
