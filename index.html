像素昼夜开关

Pixel Daylight Switch

像素风

一个装在折射玻璃开关里的微缩像素世界。拖动开关，像素场景会从白天经过黄昏自然过渡到夜晚；海边灯塔是其中一个可交互场景。

像素圆环

INTERACTIVE PIXEL WORLD

像素风

一座会随时间变化的像素小世界。拖动圆环或调整时间，观察天空、太阳、月亮、云层与房屋灯光，从清晨、正午一路变化到黄昏与深夜。

视觉版本

嵌进你的网页

<div data-pixel-orbit-embed></div>
<script src="https://gsvegetable.github.io/gongshui-open-source/embed.js" data-scene="planet"></script>

data-scene 可选 countryside（田园）、planet（星球）、world（环形世界）；data-composition 可选 art（主页那种下沉构图）或 full（完整圆环）。

投稿者地球

CONTRIBUTORS GLOBE

交互体验数据可视化

把开源项目的贡献者放到一颗可以探索的地球上。旋转地球、查看旗帜与头像、搜索作者，并从人物信息卡直接进入其作品。它让原本分散在代码仓库里的协作关系，变成一个可以被看见的世界。

收藏长廊

THE BOOKMARK HALL

空间交互程序化像素艺术

把收藏从一份列表变成一段可以走进去的空间。长廊由 Canvas 2D 射线投射实时绘制，收藏的作品会成为墙上的画框；沿着金色引导线前进，在作品前停下，再打开原本的实时作品。

02 / SPATIAL INTERACTION

Canvas 2D · Ray casting · Procedural environment

导航交互系统

NAVIGATION INTERACTION SYSTEM

界面设计微交互

以网站现有的马里奥方块导航为基础，延展出 24 枚同一视觉体系的按钮。保留原有的奶油黑描边、琥珀黄配色、硬阴影与按压位移，让每枚按钮都像来自同一套界面语言。按钮样本直接展示在作品卡片中，可以逐个按压体验。

03 / INTERFACE SYSTEM

Pixel buttons · Tactile feedback · Interaction states
