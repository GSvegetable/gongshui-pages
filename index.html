01Pixel Daylight Switch

像素昼夜开关

像素风

把时间做成一件可以亲手操作的物件。拖动开关，光线沿着清晨、正午、黄昏与夜晚连续流动；天空色温、环境亮度与场景细节同步响应。它不是在几个预设画面之间跳转，而是让你亲自经过一天。

查看项目↗ 实验室↗

场景选择

一枚开关的尺度

OBJECT / ATMOSPHERE

设计从实体拨杆的明确手感出发：边界清楚、方向明确、反馈直接。真正发生变化的却不止按钮本身——光线在场景里扩散，色彩逐渐沉静，环境也随时间改变。硬朗的像素结构与柔和的光影变化，共同构成作品的视觉性格。

交互被刻意保持简单，让注意力留给变化本身。你可以快速拨到某个时刻，也可以缓慢拖动，观察过渡中的细节；同一条时间轴，在不同场景里会呈现不同的氛围。

嵌入你的网页

<script src="https://gsvegetable.github.io/gongshui-open-source/pixel-daylight-switch/embed.js" data-scene="seaside"></script>

作品会出现在这段脚本的上方。想换场景就把 data-scene 改成 countryside / japanese-street / apartment / seaside / mountain-cabin。

拨动时间

THE CORE IDEA

核心不是“开”与“关”，而是中间那段值得观看的过程。时间进度驱动多组视觉参数连续插值，让日夜交替拥有速度、层次与情绪，而不是简单切换两张背景图。

场景承担的是叙事，而不只是装饰。同一个时间位置落在乡间小屋、街道、公寓或海边，会因为空间结构与光源不同，产生各自的明暗关系。时间因此成为连接多个微缩世界的共同语言。

交互方式拖动 · 切换 · 连续过渡
视觉语言像素场景 · 折射玻璃
体验重点时间感与氛围变化
作品类型可交互界面实验

02INTERACTIVE PIXEL WORLD

像素圆环

像素风

把昼夜变化组织成一条可操作的轨道。太阳与月亮沿着圆环移动，天空、云层、地表和建筑灯光随时间联动；你既可以直接拖动轨道，也可以切换构图，观察同一套时间逻辑如何塑造不同的世界。

查看项目↗ 实验室↗

视觉版本

不止一种构图

COMPOSITION STUDY

三个版本对应三种观看距离：星球版先建立完整世界的整体感；田园版把视线带回房屋与地景的日常尺度；环形世界版则让轨道成为画面的主角。构图改变了观看入口，但时间系统始终保持一致。

版本切换不是更换皮肤，而是一次构图实验：当主体从球面转向建筑，再转向轨道本身，时间的运动会被怎样理解？作品用三种空间关系回答同一个问题——如何让抽象的时间变得可见、可触摸。

嵌进你的网页

<div data-pixel-orbit-embed></div>
<script src="https://gsvegetable.github.io/gongshui-open-source/embed.js" data-scene="planet"></script>

data-scene 可选 countryside（田园）、planet（星球）、world（环形世界）；data-composition 可选 art（主页那种下沉构图）或 full（完整圆环）。

让世界转起来

A WORLD IN MOTION

圆环把时间变成空间中的路径。拖动位置，不只是移动一个装饰物，而是在改变世界所处的时刻：天空色彩、日月位置、云层状态与建筑灯光共同响应，让变化发生在整个场景，而不是单一控件上。

轨道同时承担刻度与构图两种职责。它给时间一个方向和距离，也把太阳、月亮与场景中的光线组织在同一套视觉秩序里。

核心机制圆环拖动 · 时间映射
环境变化天空 · 日月 · 云层 · 灯光
体验方式连续探索与版本切换
视觉方向像素微缩世界

03CONTRIBUTORS GLOBE

投稿者地球

交互体验数据可视化

把开源协作从仓库列表带到地理空间。地球上的标记提供探索入口，旋转与缩放建立整体方位，选中标记后再进入贡献者资料。原本分散在提交记录里的名字，由此获得了位置、距离与彼此之间的联系。

查看项目↗实验室↗

交互体验

交互围绕“发现—定位—了解”展开：先从整体观察标记分布，再旋转地球寻找感兴趣的位置，最后打开对应资料。当前展示模式不提供投稿入口，也不会替访问者提交任何内容。

Globe.gl · Three.js · Contributor network

让数据拥有位置

VISUAL PRINCIPLE

地图视角负责呈现整体分布，标记负责建立索引，资料卡负责补充人的信息。三个层级逐步靠近，让数据从抽象坐标变成可理解的个体与关系。

它没有要求用户按固定顺序阅读。你可以从任意位置开始，沿着地球表面自由移动，在整体与个体之间切换视角。

嵌入你的网页

<script src="https://gsvegetable.github.io/gongshui-open-source/contributors-globe/embed.js?v=1.3.0" data-flag="0" data-height="420px"></script>

默认不显示投稿入口。需要展示自己的投稿者名单时，可通过 data-contributors-src 指向你自己托管的 HTTPS JSON 数据文件。

从名字到世界

PEOPLE / PLACES

代码仓库擅长记录“谁参与了什么”，却不擅长呈现协作者之间的地理关系。投稿者地球把这类信息转译成空间标记，让分布、距离与个体资料能够在同一个界面里被理解。

它既是一张可旋转的地理画布，也是一种社区索引。拖动改变视角，标记帮助定位，资料卡连接到具体贡献者与作品；浏览路径由用户自己决定，而不是被固定列表限定。

主要对象贡献者与地理位置
浏览方式旋转 · 缩放 · 搜索
信息呈现旗帜 · 头像 · 个人资料
实现方向Globe.gl · Three.js

04THE BOOKMARK HALL

收藏长廊

空间交互程序化像素艺术

把收藏从纵向列表转译成一座可以进入的建筑。每一件内容成为墙面上的画框，远处先形成整体节奏，靠近后才显露具体作品。前进、回望与停留，让“找收藏”变成一次有方向感的空间漫游。

查看项目↗实验室↗

空间体验

在长廊中移动视角，观察两侧画框的排列；靠近目标后打开对应内容。组件只呈现宿主页面主动传入的数据，不读取访问者的账号或本地收藏，也不连接任何特定网站账号。内容边界由接入方明确控制。

Canvas 2D · Ray casting · Data-driven environment

收藏也可以被漫游

SPATIAL INDEX

传统列表把所有条目压在同一平面上。长廊则用距离、透视和画框密度组织内容：远处负责吸引视线，近处负责提供细节，移动本身成为筛选与发现的一部分。

它并不试图取代搜索、筛选或普通列表，而是提供另一种入口：当你想重新发现收藏、而不是快速定位某一条目时，空间浏览能带来不同的节奏。

嵌入你的网页

<script src="https://gsvegetable.github.io/gongshui-open-source/bookmark-hall/embed.js?v=1.2.0" data-icons="0"></script>
<script>
  const hall = document.querySelector('[data-gongshui-embed="bookmark-hall"]').gongshuiEmbed;
  hall.ready.then(() => hall.setItems([
    { id: 'work-a', title: '我的作品', src: 'https://example.com/work-a' }
  ]));
</script>

长廊需要由你自己的页面调用 setItems() 传入收藏列表。示例中的作品名称和网址请替换成你自己的内容；组件不会擅自读取访客的收藏。

走进收藏

A WALKABLE ARCHIVE

收藏长廊把信息架构变成空间架构。条目之间的距离、画框的排列和视线的方向共同构成一张可漫游的索引；发现内容不再只依赖滚动，而是通过移动与观察逐步完成。

空间本身就是索引，画框就是入口。接入方通过接口主动传入要展示的项目，长廊负责呈现与导航，不会越过宿主页面读取访问者的账号或私人收藏。

空间形式可探索的像素长廊
浏览动作前进 · 后退 · 靠近
内容来源由宿主页面主动传入
技术方向Canvas 2D · Ray casting

05NAVIGATION INTERACTION SYSTEM

导航交互系统

界面设计微交互

以 24 枚像素按钮为样本，拆解界面里最短暂、却最影响手感的动作。每枚按钮都可以拥有独立的按压位移、回弹节奏与触发反馈；它们既能单独展示，也能组合成一套有秩序的交互语言。

查看项目↗实验室↗

微小动作，明确反馈

MOTION LANGUAGE

微交互的质量往往藏在几帧之内：按下时是否有重量，回弹是否干净，停顿是否恰到好处。动作不必夸张，但必须让用户感到输入被准确接收。

这套系统把按钮动作拆成可观察的样本：同样的输入可以采用不同的位移、缓动与延迟，再通过并列比较找到最合适的反馈节奏。

嵌入你的网页

<script src="https://gsvegetable.github.io/gongshui-open-source/navigation-interaction/embed.js?v=1.4.2"></script>

默认展示完整的 24 个按钮。可用 data-sample="7" 只显示一个样本，或用 data-samples="0,2,7,14" 组合多个按钮。

让按钮有自己的性格

MICRO INTERACTIONS

按钮不仅承载图标，也承载动作反馈。位移幅度决定按压重量，回弹曲线决定轻快或克制，触发后的状态变化则决定操作是否清晰。

24 枚按钮分别探索不同的动作性格：有的强调快速响应，有的保留短暂停顿，有的通过连续反馈建立节奏。单个样本可以独立体验，也可以放进组合中观察彼此的协调关系。

组件数量24 枚像素按钮
视觉状态黑白图标
交互反馈按压 · 回弹 · 延迟
设计重点独立动效与联动
