隐私政策

01 · 适用范围与服务架构

宫水.com 是以静态网页为主体的个人作品展示网站。账号认证及云端数据存储由 Supabase 提供。本文所称“本站”或“我们”，指宫水.com 网站运营方；“服务商”指为网站提供托管、认证、数据库或身份验证能力的第三方服务提供方。

本政策仅适用于本站可控制或配置的数据处理活动。访问外部作品、第三方网站或服务时，相关服务商可能依据其自身政策独立处理信息。

02 · 处理的信息类别

2.1 账号与身份信息

使用邮箱注册或登录时，Supabase Auth 处理账号邮箱、密码验证材料、账号唯一标识、邮箱验证状态、创建时间及最近登录时间。密码验证由认证服务执行，本站不会将用户输入的明文密码写入本站自有业务表。

使用 Google 或 GitHub 登录时，认证服务会接收完成身份验证所需的提供方身份信息。本站使用认证结果建立本站账号，并可能读取提供方返回的基本资料，例如邮箱、显示名称、用户名及头像地址。本站不请求访问 GitHub 仓库、Google Drive 等与登录无关的资源权限，也不会将提供方访问令牌作为本站业务数据保存。

2.2 注册安全信息

为识别短时间内的异常重复注册，注册流程可能生成随机浏览器标识。原始随机值保存在当前浏览器 localStorage，提交至 Supabase 的为其 SHA-256 摘要。本站不通过 Canvas、屏幕尺寸、硬件线程数、语言或时区等浏览器特征构建设备指纹。公开浏览作品不会触发该标识生成。

注册风控记录包含账号 ID、用户名及登记时间，用于计算 24 小时风险窗口。自 2026 年 11 月 14 日起，新注册流程不再主动收集或保存 IP 地址；历史风控记录可能仍包含此前产生的 IP 信息。IP 地址不会单独触发本站当前的账号限制。

为防止用户名登录及账号关联接口被反复尝试，本站会对规范化后的用户名或邮箱生成带服务端密钥的 HMAC-SHA-256 摘要，并记录短期请求次数。本站不在该限流记录中保存明文用户名、邮箱或 IP 地址；同一标识在 15 分钟内超过允许次数时会被暂时限流，摘要记录最长保留 24 小时后清理。

在注册或修改密码时，本站会检查新密码是否出现在已知泄露密码库中。本站在服务端计算密码的 SHA-1 摘要，只向 Have I Been Pwned Pwned Passwords 发送摘要的前 5 个字符，并在本站完成完整匹配；不会向该服务发送明文密码或完整摘要，也不会保存密码摘要。该检查采用 k-anonymity 方式；若检查服务暂时不可用，本站会要求稍后重试。

2.3 网站内容与偏好

登录用户的作品收藏、收藏夹结构及部分界面偏好（例如布局、缩放和场景选择）可同步至 Supabase。未登录时，相关数据可能仅保存在当前浏览器的本地存储中。

2.4 登录会话与技术信息

为维持登录状态并支持同一设备上的账号切换，浏览器本地存储会保存当前账号及已关联账号的 Supabase 刷新令牌。用户选择“退出所有账号”时，本站会清除当前设备保存的全部关联账号刷新令牌，并结束当前账号会话；其他已关联账号的服务器端会话以及其他设备上的登录会话不会因此自动撤销。本站托管平台及认证服务商也可能依据其运行机制处理访问日志、网络请求信息和安全诊断数据；具体范围及保存期限以相应服务商的政策和配置为准。

03 · 信息处理目的

  • 创建、验证、维护及恢复用户账号；
  • 识别 Google、GitHub 等第三方身份，并完成本站登录；
  • 同步用户收藏、收藏夹和已选择的网站偏好；
  • 识别短时间内异常重复注册，保护账号服务及管理功能；
  • 维护网站运行、安全性及服务稳定性。

本站不会将注册安全标识用于跨站广告画像，也不会出售用户账号资料。

04 · 第三方服务与信息共享

本站使用 Supabase 提供身份认证及数据库服务。第三方登录由用户主动选择的 Google 或 GitHub 提供身份验证。用户跳转至相应服务商页面后，其登录、授权及数据处理活动同时受该服务商隐私政策约束。

本站仅接收完成登录及账号展示所需的基本身份资料，不以第三方登录为由申请访问用户的云盘、代码仓库或其他无关内容。本站不会将用户资料出售给广告商；除提供服务所必需的服务商处理、用户主动授权或法律要求外，不主动向无关第三方披露账号资料。

部分作品预览可能加载 GitHub Pages 等外部托管内容。加载时，浏览器会直接向相应域名发出网络请求，该请求受相关服务商的政策约束。

05 · 保存期限与删除机制

  • 注册风控记录：用于 24 小时风险窗口，数据库定期清理超过 24 小时的记录，通常最迟约 24 小时 5 分钟完成清理。
  • 登录限流摘要：仅保留 HMAC 摘要及请求计数，最长 24 小时后清理。
  • 浏览器随机标识：保留在当前浏览器，直至用户清除本站点数据或手动清理相关存储；退出登录不会自动删除该标识。
  • 收藏与偏好：云端数据与账号关联，按账号服务的保存状态保留；账号删除时，相关业务记录按数据库关联规则处理。
  • 会话令牌：刷新令牌保存在当前设备以支持账号切换；选择退出所有账号时，本站清除当前设备保存的全部关联账号令牌。其他已关联账号的服务器端会话及其他设备上的会话不受此操作影响。
  • 历史网络信息：历史风控记录可能包含 IP 地址，相关记录按既有风控数据清理机制处理。

如需删除账号及云端关联数据，请通过本站公开渠道联系运营者。本站目前未设置专用隐私联系邮箱。请勿通过公开评论或普通消息提交密码、验证码、刷新令牌等认证凭据。

06 · 安全措施与责任边界

本站通过 HTTPS、Supabase Auth、数据库行级安全策略及受限的管理数据库函数保护账号和业务数据。本站遵循必要性原则，不在前端部署 service_role 或其他服务端特权密钥。

互联网服务无法承诺绝对安全。由于当前网站采用浏览器端会话机制，能够访问用户设备或利用浏览器脚本漏洞的第三方仍可能对本地会话造成风险。建议使用独立且强度足够的密码，不在公共或他人设备上保持登录，并及时更新浏览器。

本政策描述的是本站代码及当前已知配置所体现的数据处理方式。服务商自身的日志、基础设施安全措施及数据保留规则，仍以服务商公布的文件和实际配置为准。

07 · 用户的选择与控制

  • 用户可以选择不注册账号，继续浏览公开作品；
  • 用户可以选择邮箱、Google 或 GitHub 作为登录方式；
  • 用户可以在账号设置中退出登录，并在浏览器设置中清除本站点数据；
  • 用户可通过相应第三方账号的安全设置管理或撤销对本站的授权；
  • 用户可请求查询或删除与本站账号关联的数据，本站将在可用的管理渠道内处理。

第三方身份不会被本站静默合并到既有账号。若需将第三方身份关联到已有账号，应先通过既有账号完成身份验证，并使用明确的账号绑定流程。

08 · 政策更新

当网站功能、数据处理方式或适用要求发生变化时，本站可能更新本政策。更新后的版本将在本页面公布，并同步调整生效日期。建议用户在使用账号功能前查看本页面的最新内容。
