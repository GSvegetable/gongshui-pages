# 宫水.com

> 个人作品与交互实验展示空间。以简洁的界面呈现网页作品、视觉实验和可复用组件。

| 项目信息 | 内容 |
|---|---|
| 在线地址 | [https://宫水.com](https://xn--3bts89a.com/) |
| 项目仓库 | [GSvegetable/gongshui-pages](https://github.com/GSvegetable/gongshui-pages) |
| 当前版本 | `v2.12.8` |
| 主要语言 | HTML、CSS、JavaScript |
| 网站托管 | GitHub Pages |
| 账号与数据服务 | Supabase |

## 项目内容

| 模块 | 说明 |
|---|---|
| 作品展示 | 展示个人制作的网页组件、视觉实验与交互作品 |
| 像素昼夜开关 | 可在白天、黄昏和夜晚之间切换的微缩像素场景 |
| 像素圆环 | Pixel Orbit 像素视觉实验 |
| 账号系统 | 支持邮箱/用户名登录，以及 Google、GitHub 第三方登录 |
| 个人功能 | 提供收藏、快捷导航和个人账号设置等功能 |
| 多语言 | 支持中文、英文及日文界面 |

## 技术与服务

| 部分 | 使用方案 | 主要职责 |
|---|---|---|
| 前端 | HTML / CSS / JavaScript | 页面结构、样式与交互 |
| 代码管理 | GitHub | 源码、版本记录与协作 |
| 网站部署 | GitHub Pages | 发布静态网站 |
| 身份认证 | Supabase Auth | 用户注册、登录与身份验证 |
| 数据存储 | Supabase Database | 保存网站所需的用户数据 |
| 辅助检查 | TinyFish（外部工具） | 按需检查网页实际呈现与操作流程 |

## 开发与发布

| 步骤 | 工作方式 |
|---|---|
| 1. 修改 | 在本地或 GitHub 中修改项目代码 |
| 2. 保存 | 通过 Git 提交变更，保留历史版本 |
| 3. 检查 | 发布前检查页面、交互与关键功能 |
| 4. 发布 | 将确认后的修改合并到主分支，由 GitHub Pages 发布 |
| 5. 验证 | 检查线上页面是否与预期一致 |

**维护原则：** 优先小范围修改；涉及登录、数据库或线上配置时先检查影响范围；保留可追溯的版本记录，避免未经验证的大规模变更。

## 像素昼夜开关嵌入方式

可以将像素昼夜开关嵌入其他网页。将下面的脚本放入页面中，作品会显示在脚本所在位置附近。

```html
<script
  src="https://gsvegetable.github.io/1_pixel-daylight-switch/embed.js"
  data-scene="seaside"
></script>
```

可选场景：`countryside`、`japanese-street`、`apartment`、`seaside`、`mountain-cabin`。
