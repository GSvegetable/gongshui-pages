## 项目简介

**宫水.com** 是一个持续迭代的个人作品与交互实验展示空间。项目围绕网页设计、前端交互和视觉表达展开，集中展示独立制作的网页作品、实验性组件及个人功能。

项目强调清晰的信息层级、细致的交互体验与可持续维护。网站功能、服务和版本状态以仓库代码及线上实际表现为准。

## 核心内容

| 模块 | 说明 |
| --- | --- |
| 作品展示 | 展示个人制作的网页组件、视觉实验与交互作品 |
| 像素昼夜开关 | 在白天、黄昏和夜晚之间切换的微缩像素场景 |
| Pixel Orbit | 以像素视觉语言构建的圆环交互实验 |
| 账号系统 | 支持邮箱、用户名，以及 Google、GitHub 第三方登录 |
| 个人功能 | 收藏、快捷导航与个人账号设置 |
| 多语言界面 | 支持中文、英文与日文 |

## 账号与安全

项目持续完善账号流程与数据访问边界，当前文档记录的措施包括：

- **登录保护**：对登录流程增加必要的校验与尝试限制。
- **会话管理**：检查会话有效性，并处理账号状态变化。
- **密码安全**：提高密码要求，并在支持的流程中检查已知泄露密码。
- **数据访问**：按用户身份和权限限制数据访问。
- **管理功能**：对管理操作进行权限验证。
- **隐私保护**：减少不必要的信息收集，并说明相关数据处理方式。

> 安全措施会持续完善。第三方服务的限制、平台配置与线上环境仍需单独核验；以上说明不构成绝对安全承诺，也不代表所有外部登录场景均已完成实测。

## 组件嵌入

### Pixel Daylight Switch

可以将像素昼夜开关嵌入其他网页。将以下脚本放入目标页面，即可在脚本所在位置附近加载组件。

```html
<script
  src="https://gsvegetable.github.io/gongshui-open-source/pixel-daylight-switch/embed.js"
  data-scene="seaside"
></script>
```

可选场景：

`countryside` · `japanese-street` · `apartment` · `seaside` · `mountain-cabin`

## プロジェクト概要

**宫水.com** は、Web デザイン、フロントエンド開発、ビジュアル表現を中心とした個人作品・インタラクション実験の公開スペースです。独自に制作した Web 作品、実験的な UI コンポーネント、個人向け機能を継続的に公開・改善しています。

情報設計の明快さ、丁寧な操作体験、長期的な保守性を重視しています。機能・サービス・バージョンの最新状態は、リポジトリ内のコードおよび公開サイトを基準とします。

## 主な機能

| 項目 | 説明 |
| --- | --- |
| 作品ギャラリー | 個人制作の Web コンポーネント、ビジュアル実験、インタラクティブ作品 |
| Pixel Daylight Switch | 昼・夕暮れ・夜を切り替えられるドット絵のミニチュア風シーン |
| Pixel Orbit | ピクセル表現を用いた円環型インタラクション実験 |
| アカウント | メールアドレス・ユーザー名、および Google・GitHub によるログイン |
| 個人向け機能 | お気に入り、クイックナビゲーション、アカウント設定 |
| 多言語対応 | 中国語・英語・日本語 |

## アカウントとセキュリティ

アカウント機能とデータアクセス制御を継続的に改善しています。現在のドキュメントに記載されている主な対策は以下のとおりです。

- **ログイン保護**：ログイン時の検証と試行回数の制御。
- **セッション管理**：セッションの有効性を確認し、アカウント状態の変化に対応。
- **パスワード保護**：パスワード要件の強化と、対応フローにおける既知の漏えいパスワードの確認。
- **データアクセス**：ユーザーの本人確認状態と権限に応じたアクセス制御。
- **管理機能**：管理操作に対する権限確認。
- **プライバシー**：不要な情報収集を抑え、データの取り扱いを明確化。

> セキュリティ対策は継続的に改善されています。外部サービスの仕様、プラットフォーム設定、本番環境については個別の確認が必要です。これらの説明は完全な安全性を保証するものではなく、すべての外部ログイン経路の実機検証完了を意味するものでもありません。
